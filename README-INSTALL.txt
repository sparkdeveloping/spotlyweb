Spotly Marketplace Editorial Pack

This pack contains 94 optimized editorial/category photographs from the Spotly photography packs supplied in this project.
Copy the included public/marketplace/editorial-pack folder into the root of the corrected Spotly Next.js project before deployment.

These images are intentionally used as generic category/editorial imagery when a marketplace record has no merchant-approved image. They must not be represented as proof that a specific merchant, menu item, product, hotel, event, driver, or location exists.
