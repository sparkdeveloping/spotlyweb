# Spotly Web Update Notes

This package contains an updated Spotly web direction aligned to the Spotly 2.0 customer prototype work.

## What changed

- Rebuilt the landing page around the stronger Spotly 2.0 product story.
- Added a more premium hero with a customer preview image.
- Added an interactive service showcase that mirrors the new product logic:
  - expressive home
  - focused service mode after selection
  - coverage for Ride, Eat, Shop, Book, Events, and Send
- Added production-oriented launch notes and next-step sections.
- Added preview imagery into `/public`.

## Main files

- `app/page.tsx` — rebuilt landing page
- `components/SpotlyWebShowcase.tsx` — interactive service-mode showcase
- `public/spotly-customer-preview.png` — full preview image
- `public/preview-*.png` — cropped preview assets

## Notes

- This is a strong updated source package intended for continued iteration by implementation agents.
- It is source-first and may still benefit from final image replacement, SEO refinement, analytics, forms, and deeper route expansion.
